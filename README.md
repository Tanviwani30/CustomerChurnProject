# Customer Churn Analysis and Prediction Using Data Analytics and Machine Learning

## Project Overview

This project analyzes customer churn using data analytics and machine learning techniques.

The main objective is to understand customer behavior, identify factors associated with customer churn, and build a machine learning model to predict whether a customer is likely to churn.

The project uses the IBM Telco Customer Churn dataset and Logistic Regression for prediction.

---

## Objectives

- Analyze customer churn patterns.
- Clean and preprocess customer data.
- Perform Exploratory Data Analysis (EDA).
- Visualize important customer characteristics.
- Identify factors associated with customer churn.
- Build a Logistic Regression model.
- Evaluate the model using classification metrics.
- Generate customer churn predictions.

---

## Dataset

The project uses the IBM Telco Customer Churn dataset.

### Dataset Details

- Records: 7,043
- Columns: 21
- Target Variable: `Churn`
- Churn = Yes: 1,869
- Churn = No: 5,174
- Overall Churn Rate: Approximately 26.54%

## Machine Learning Model

### Logistic Regression

Logistic Regression is used as the classification algorithm to predict whether a customer is likely to churn.

The model uses customer and service-related features to predict two classes:

- No Churn
- Churn
